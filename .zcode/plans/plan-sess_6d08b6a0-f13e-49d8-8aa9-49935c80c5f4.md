# 液态玻璃质感修复与性能优化方案

## 诊断结论（已逐行验证）

明暗两种模式下质感差不是单一参数问题，而是 **4 个渲染 bug + 1 组材质参数失衡** 叠加：

1. **模糊两轴不对称（所有非高配档）**：`liquid-glass-canvas.tsx:1027` vblur 用全屏分辨率、`:1036` hblur 用降采样分辨率。当前所有桌面都落在 blurBufferScale 0.5 档 → 横向模糊半径是纵向的 2 倍（36px vs 18px），且 5-tap 稀疏核在 ±18/36/54/72px 产生鬼影分身 → 玻璃内部横向拖影、发闷。
2. **桌面 DPR 被永久砍到 1.35**：`liquid-glass-runtime.ts:215` 的 `cardCount >= 10` 触发降档，页面注册约 14 张卡片 → 包括 Retina Mac 在内的所有桌面都以 67.5% 分辨率渲染玻璃壳层 → 折射边缘模糊发虚。卡片绘制是 scissor 裁剪的，成本随视口而非卡片数缩放，该降档依据不成立。
3. **veil 烘焙进折射源且暗色方向反了**：bg pass 把页面遮罩直接混入玻璃采样纹理。暗色 `--glass-scene-veil-strength: 1.06`（globals.css:110）让玻璃内部比页面背景**更黑**（最高 ~61% 黑混合），叠加 sceneCoverage 0.93-0.99 → 暗色模式是"泥灰色石板"；亮色 0.88 → 最高 ~37% 白洗 + 高覆盖率 → "平板白色矩形"，玻璃毫无材质感。
4. **色散不可见 + 亮色边缘高光被压半**：IOR split ±0.018 下色散最大仅 ~0.8px（亚像素）；`glass-main.glsl:227` 高光应用系数 `0.42 + darkBackground*0.58` 在亮背景（亮色模式）下直接砍半；counter-rim 最深只压暗 2.4% → 亮色边缘干瘪无立体感。另有死 uniform `u_fresnelRange`（每帧设置但 shader 从不读取）。
5. **主题注入 bug（已确认修复）**：`layout.tsx:56-62` 把 site.ts 按暗色设计的令牌（#ff375f、纯黑渐变）以内联样式注入 `<html>`，无差别覆盖亮色模式的设计令牌。

次要问题：首张背景纹理到达时 `u_bgReady` 0→1 硬切换造成 coverage 0.075→0.9x 跳变；1×1 白色 fallback 纹理在暗色模式加载期有白闪风险；高配档 RGBA16F 全屏 FBO（5K 下 118MB）带宽浪费（内容全程 LDR）。

## 实施方案

### Phase 1 — 渲染管线 bug 修复
- **模糊对称修复**（`liquid-glass-canvas.tsx:1022-1038`）：vblur 的 `u_resolution` 改传 `blurWidth/blurHeight`，两轴等效设备像素半径一致。
- **模糊核重整**（`liquid-glass.ts` + canvas）：`sceneBlurRadius: 18`（texel 单位，过大且稀疏）改为以 **CSS px 锚定**的目标柔化（~9 CSS px 等效），按 `dpr × blurBufferScale` 换算成 texel 半径传入；panel/dense 保持 AGENTS.md 要求的 ~8px 等效最低柔化档。若单轮 5-tap 柔化不足，追加第二轮 h+v 迭代（σ×√2，降采样 buffer 上成本可忽略）。
- **死 uniform 清理**：移除 `u_fresnelRange`（shader 声明、canvas uniform 列表与 `:1075` 传值、`GlassVariantConfig.fresnelRange` 接口字段及 5 个 variant 值）；`glass-bg.glsl` 的 `u_resolution` 同样未使用，一并移除。

### Phase 2 — 质量分级重构与性能
- **`resolveLiquidGlassQuality` 重构**（`liquid-glass-runtime.ts:194-236`）：
  - 移除 `cardCount` 降档触发（成本论据不成立）
  - 桌面默认档：`{ blurBufferScale: 0.67, dprCap: 2 }`（原来高配档 blur=1，全分辨率 blur buffer 本身就是浪费）
  - 新增低核心桌面降档（`hardwareConcurrency <= 4`）：`{ 0.5, 1.5 }`
  - coarse 指针 / 低内存 / dpr≥3 档 `{ 0.5, 1.35 }` 与 saveData/极低内存档 `{ 0.38, 1.1 }` 保持不变
  - `preferHalfFloat` 字段整体移除 → FBO 全部 RGBA8（内容 LDR，带宽减半）
- **场景缓冲上限**：fbo0 尺寸上限 1.5× CSS px（`min(dpr, 1.5)` 缩放）。5K Retina 下 5120×2880 → 3840×2160（RGBA8 33MB，对比原 16F 118MB）。卡片 pass LINEAR 上采样，rim 仍在全分辨率下由 shader 计算，清晰度不受影响。
- **bgReady 渐入**：`u_bgReady` 由 0/1 硬切换改为 ~450ms ease-out ramp（render loop 内推进，未完成时持续自调度重绘），消除背景纹理到达瞬间的覆盖率跳变。
- **主题感知启动纹理**：`createFallbackBackgroundTexture` 按当前 colorScheme 提供中性色（light 白 / dark `#0a0a0f` 深灰）。
- 同步更新 `liquid-glass-runtime.test.ts` 档位断言（新增"14 卡桌面不再降档"用例，改写 coarse 用例）。

### Phase 3 — 清透镜片材质调参（用户已选方向）
约束：`sceneCoverage >= 0.88`（`liquid-glass.test.ts:90` 锁定的下限）、dark ≥ light、文字密集中心保留柔化档、色散与强 glare 不进中心。

- **veil**（`globals.css:32,110` + `globals.test.ts:54` 断言同步）：
  - light `--glass-scene-veil-strength` 0.88 → **0.6**
  - dark 1.06 → **0.8**
  - DOM 页面层 overlay 不动 —— 只让玻璃内部采样源比页面更干净（镜片物理直觉）
- **材质 profile**（`liquid-glass.ts`，目标值，实现时按截图微调）：
  - light：sceneCoverage hero/panel/media/dense/immersive = 0.93/0.92/0.90/0.88/0.94（各降 ~0.03）；saturation 1.16-1.24；exposure 1.03-1.05；edgeHighlightGain 1.35-1.55；edgeShadowGain 0.95-1.15
  - dark：sceneCoverage 0.93/0.92/0.90/0.89/0.94（大幅脱离 0.97-0.99 石板感）；saturation 1.20-1.28；tintAlpha 0.05-0.062（材质识别度随覆盖率下降回补）；edgeHighlightGain 1.40-1.70；edgeShadowGain 1.05-1.22
- **shader 调整**（`glass-main.glsl`）：
  - 色散可见化：IOR split 0.018 → 0.026，chroma 系数 `(0.54 + bevelBody*0.14)` → `(0.85 + bevelBody*0.22)` → 强 rim 上红蓝分离 ~2-3 设备 px（hero/immersive 明显、dense 克制），仍由 edgeField 门控不触及文字中心
  - 亮背景高光地板：`:227` 应用系数 `0.42` → `0.58`（修复亮色模式高光减半）
  - counter-rim 基础暗量 `:220` 0.010 → 0.02（亮色边缘立体感）

### Phase 4 — 主题注入修复（用户已确认）
- `layout.tsx`：移除 `<html>` 内联 style，改为注入 `<style>` 标签，site.ts 配置令牌包在 `@media (prefers-color-scheme: dark) { :root { ... } }` 内
- 亮色模式恢复 globals.css 设计令牌（tint #c8005d、白色渐变）；`data-liquid-glass="loading"` 等属性不动

### Phase 5 — 文档同步与验证
- 更新 `AGENTS.md` Performance Notes（质量分级新逻辑、RGBA8/场景缓冲上限、veil 策略、模糊管线、bgReady 渐入）与 `README.md` 对应段落（25/26/180/181 行附近）
- `pnpm test:unit`（同步 `globals.test.ts` veil 断言 0.88→0.6 与档位断言）
- `pnpm build` 静态导出通过
- dev server + 浏览器截图验证：亮/暗 × 桌面(2560px)/移动(390px)，检查玻璃中心清澈度、rim 高光、色散可见性、无横向拖影、背景切换与首帧无跳变
- 性能 sanity：背景切换 2s 期间与滚动的帧时间平稳

## 明确不做的事
- 不改页面布局、网格结构、卡片 DOM 层级与交互逻辑
- 不动失效驱动渲染调度、文档坐标几何缓存、背景切换同步等既有架构（这些设计是对的）
- 不动 NowPlayingCard 独立 iOS 材质（其亮色模式白字对比问题是独立小项，可后续单独处理）
- 不处理 `@callcall/liquid-glass` 未使用依赖（可选清理，不在本次范围）
