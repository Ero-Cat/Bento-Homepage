# 液态霜面填满整卡修复方案（空白边根修）

## 根因
`glass-main.glsl` 的材料在离边 8-15px 处三重突变：霜面混合（cleanCenter 阶跃 + rim 带仅 0.04-0.24）、覆盖率（边缘带 ×0.72 更透明）、中心放大系数阶跃。霜面渐变在同一位置截断 → 内部渐变未填满卡片 + 空白边 + 过渡不均匀。此前所有"边缘线"修复都治错了地方。

## 正确光学设计（按 Apple 图二"液态模糊"）
整卡连续霜面为基底，折射位移作用于**已模糊**的背景（= 液态模糊弯折）；边缘不再有独立的"清晰折射带"，只有薄镜像条略微清晰化。

## 修改内容（全部在 glass-main.glsl + 测试/文档）

### 1. 覆盖率平铺填满
`float centerSceneCoverage = readySceneCoverage;`（删除 ×0.72 边缘带凹陷，玻璃材料覆盖到边）

### 2. 霜面连续化
- `centerDiffusion = clamp(u_surfaceBlurMix * (0.92 + wideField * 0.18), 0.0, 0.62)` —— 连续霜面，rim 略深，无 cleanCenter 阶跃
- `bevelGlass` blurMix：`clamp(u_surfaceBlurMix * (0.95 - mirrorBand * 0.35), 0.0, 0.62)` —— rim 带与中心同材质，仅薄镜像条（1.2-9px）略微清晰

### 3. 放大平滑化
`surfaceLensOffset` 系数 `(0.55 + cleanCenter×0.45)` → `(1.0 - wideField×0.5)`（连续，rim 由折射主导）

### 4. 清理死代码
移除 main() 中不再使用的 `normalizedLocal` 块

### 5. 测试同步
entrance-animations.test.ts：`centerSceneCoverage = mix(...)` 正则改为断言平铺填充（`centerSceneCoverage = readySceneCoverage;`），语义更新为"霜面必须填满整卡"

### 6. AGENTS.md
更新三段式壳层约束为「液态霜面铁律」：霜面填充 100% 卡片面积、rim = 位移弯折的霜面、禁止任何材料在距边 8-15px 处截断

## 验证
1. **霜面边界检测**：垂直剖面局部方差——霜面（低方差）必须延伸到 rim；修复前在 ~10px 处方差回升（清晰环）
2. 条纹位移测试：折射仍可见（弯折的是霜面）——液态模糊效果确认
3. 标准：85 单测 + build + 边缘剖面 + 明暗全页状态 + 60fps
4. 与 Apple 图二对照截图（亮/暗模式）

- 不动布局、CSS 接触阴影保持
- mipmap/自适应扩散等已验证的修复全部保留
